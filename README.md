# mini vector database

a mini vector database i made for learning purposes.

implements cosine similarity and euclidean distance comparison.

basic linear search for comparing vectors.

# compilation

to compile you can do `cc src/vdb/vdb.c src/main.c -o out/vdb -std=c99`
